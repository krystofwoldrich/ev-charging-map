# Native map UI and release updates — 2026-10-16

Version/runtime: **1.1.0**, Expo SDK 58. iOS identity remains `ch.woldri.evchargingmap` (App Store Connect app `6749909889`).

## Implementation

- One native TrueSheet presentation for search, station details, and Settings; default iOS Liquid Glass at floating detents, system presentation when expanded.
- System typography, semantic colors, SF Symbols, native text fields/switches, accessible control labels, 44-point targets, and Reduce Motion-aware map movement.
- Accessibility text sizes expand the sheet and stack station price/power and connector tariffs.
- Fictional Amsterdam data is the default. Live Plugsurfing and sample queries use separate cache keys. The setting survives restarts and OTA updates.
- Release-only update picker with Stable, Preview, named channels, recent choices, runtime compatibility, download error recovery, and native-sheet dismissal before reload. Updates are explicitly selected rather than downloaded automatically.
- Missing opening hours stay unknown. Price comparisons prioritize energy tariffs; unknown time units are not labeled as per-minute prices.
